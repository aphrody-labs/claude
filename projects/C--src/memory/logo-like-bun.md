Logo: the GitHub avatar of the aphrody-labs org, committed once as docs/logo/aphrody.png, the way Bun has docs/logo/bun.png. READMEs, the site favicon and the profile repos use that file, or the avatar URL in the profile repos. docs/icons holds only icons that a doc actually displays.

On 2026-11-15 the owner ordered the brand system deleted: packages/design/brand, src/ui/kit/src/brand, `ay brand`, brand.just, docs/badges, the generated logos and tiles, the zukan palette crawl. He called it hallucinated by an agent.

**Why:** an agent invented a whole brand pipeline (mark, wordmark, tiles, palette crawl, generator) on top of a logo that already existed.

**How to apply:** do not rebuild any brand tooling, and do not generate logos, icons or palettes. Copy Bun's layout exactly and add nothing without a real consumer ([[agent-report-vs-request]], [[licenses-go-to-human]]).
