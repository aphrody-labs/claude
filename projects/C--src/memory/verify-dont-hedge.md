Forbidden to write "je n'ai pas vérifié" / "not verified" in a report.

**Why:** the user wants every claim proven, not a caveat admitting a missing check.

**How to apply:** before reporting, run the check (open the page or file, screenshot, check content); report only verified results, or say what failed when a check could not run.
