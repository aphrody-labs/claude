Owner asked (2026-11-15) to remember every request of the session, analyse my reactions and improve continuously.

**Requests, in order** (apps/open, aphrody-labs/open): English source and generalist rules (registries, no fixed picks); Bun x Material 3 deliverable (MDX -> skills -> runnable examples, Angular Material, Theme Builder theme, AOT executable, coverage of every Bun API and of the Figma M3 kit); no TypeScript 6 regression; justify Node.js (none allowed); "fini tout"; no hardcoded VPS or tool paths; no identity, PC, accounts, Windows folders, VPS or owner statements in code or config; imports verified, purged, reorganised; naming argued; the standing goal "design.google in open, C ABI, cross-platform, cross-provider AI router with API, lib, UI, CLI, GUI, TUI, shell, desktop, mobile, serverless, cloud, self-hosted, free"; a Hugging Face agent with huggingface/skills at the heart of the AI layer.

**My mistakes and the rule each one gave:**
- Added `@typescript/typescript6` to satisfy Angular's compiler instead of checking the latest-only policy first. Rule: when an upstream needs an older dependency, find a path without it (Angular JIT) before adding it, and say so.
- Ran doc examples in a sandbox under the repo; `bun add` edited the app's package.json. See [[sandbox-doc-examples-outside-projects]].
- Ran 7,000+ examples on the PC and in /tmp of the test host (tmpfs quota). Rule: heavy runs go to the fleet through a repo script, data in the user state directory, free-space guard.
- Deployed by hand on the test host (`/srv/open`, a downloaded Bun, `pkill -f` that killed my own ssh shell). Rule: a repo script, host by `ssh -G`, Bun by `ay rt`, systemd user units. See [[no-private-data-in-source]].
- Imported chromium-bun as is (Sovereign modules, fleet names, mesh subnet). Rule: import gate D25 before landing.
- A Rust git dependency on the whole monorepo for a few ABI helpers broke Windows CI (submodule path too long). Rule: shared primitives live in open (crates/c-abi); never git-depend on the monorepo.
- `bun add` in `packages/*` of open started an install of the whole root workspace. Rule: new runnable units go under `apps/` (outside the workspaces) or install at the root deliberately.
- Shell quoting losses: apostrophes inside single-quoted `bun -e`, template literals in patch scripts, `gh -q` with jq. Rule: write patch scripts to a file with a quoted heredoc; pipe `gh api` to `jaq`.
- Read "set up an agent with huggingface/skills" narrowly; the owner meant the whole huggingface.co infrastructure (Hub, Xet storage, inference, Spaces, datasets, chat). Rule: a site URL in a request means the platform behind it; scope from the site's own API description (huggingface.co/.well-known/openapi.json).
