`C:\src\ai-os` (GitHub `aphrody-dev/ai-os`) is generated from `aphrody-labs/legacy` at the rev in `extract.toml` (checkout `C:\src\legacy-rev`, shallow); never edit extracted files by hand: change `extract.toml` or add `patches/*.patch`, then `bun tools/extract.ts`. CI re-runs the extraction and fails on drift. Rust: 6 workspace members plus standalone published crates checked one by one (`bun tools/crates.ts`; known failures listed in `extract.toml [crates.known-failing]`).

**Why:** owner asked for an independent, light, reproducible AI monorepo; aphrody-dev/ay (C:\src\ay) is the rebuild of the rest and does not contain ai-os.

**How to apply:** the relay MCP in the aphrody plugin runs `frameworks/ai-os/src/relay/cli.ts` from `C:/src/ai-os` (`AI_OS_ROOT` overrides). Machine env `SRC_ROOT=C:\aphrody` is stale: unset it for ai-os tests. See [[ay-legacy-rebuild]].
